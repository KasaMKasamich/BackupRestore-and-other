Создание разделов на жестком диске Windows 10 Diskpart

Дискпарт — это утилита командной строки, которая позволяет управлять дисками и разделами на жестком диске в ОС Windows. Она может использоваться для создания, удаления, изменения размера и форматирования разделов на жестком диске. В этой статье мы разберем, как использовать Diskpart для создания разделов на жестком диске в ОС Windows 10.

Шаг 1: Открытие утилиты командной строки Diskpart

Чтобы открыть утилиту командной строки Diskpart, вам необходимо выполнить следующие действия:

  1. Нажмите клавиши «Win + R» на клавиатуре, чтобы открыть окно «Выполнить».
  2. Введите «cmd» в поле «Выполнить» и нажмите клавишу «Enter».
  3. Напишите команду «diskpart» и нажмите клавишу «Enter».

После выполнения этих действий вы попадете в окно утилиты командной строки Diskpart.

Шаг 2: Выбор диска для создания раздела

Чтобы выбрать диск для создания раздела, выполните следующие действия:

  1. Напишите команду «list disk» и нажмите клавишу «Enter».
  2. Выберите жесткий диск, на котором вы хотите создать новый раздел, написав команду «select disk X» и нажав клавишу «Enter». Замените «X» на номер диска, который вы хотите выбрать (например, «select disk 0»).

Шаг 3: Создание раздела

Чтобы создать новый раздел на выбранном диске, выполните следующие действия:

  1. Напишите команду «create partition primary» и нажмите клавишу «Enter».
  2. Введите команду «format fs=ntfs quick» и нажмите клавишу «Enter». Эта команда форматирует новый раздел в файловую систему NTFS.

После выполнения этих команд новый раздел будет создан на выбранном жестком диске и отформатирован в файловую систему NTFS.

Создание разделов на жестком диске Windows 10 Diskpart

Жесткий диск является одним из самых важных устройств в компьютере. Он хранит операционную систему, программное обеспечение и все ваши данные. Поэтому очень важно правильно организовывать хранение данных на нем. В данной статье мы рассмотрим как создавать разделы на жестком диске в Windows 10 с помощью Diskpart.

Что такое разделы на жестком диске?

Разделы на жестком диске — это логические области на физическом диске, каждый из которых выделяет отдельное пространство для файлов и папок. Каждый раздел имеет свой уникальный диск-букву, и он может быть отформатирован в определенной файловой системе. Разделы жесткого диска позволяют лучше управлять пространством на диске и увеличивать производительность компьютера.

Как создать разделы на жестком диске с помощью Windows 10 Diskpart?

  • Шаг 1: Откройте командную строку от имени администратора.
  • Чтобы открыть командную строку от имени администратора, выполните следующие действия:

    • Нажмите клавиши «Win+X», выберите «Командная строка (администратор)».

  • Шаг 2: Запустите Diskpart.
  • Введите команду «diskpart» в командной строке и нажмите Enter.
  • Шаг 3: Отобразите список дисков в системе.
  • В командной строке введите «list disk», чтобы отобразить список дисков в системе.
  • Шаг 4: Выберите жесткий диск для создания раздела.
  • Введите команду «select disk [номер диска]», где [номер диска] — это номер жесткого диска, на котором вы хотите создать раздел.
  • Шаг 5: Создайте новый раздел.
  • Введите команду «create partition primary», чтобы создать новый раздел на выбранном диске.
  • Шаг 6: Отформатируйте новый раздел.
  • Введите команду «format fs=ntfs quick», чтобы отформатировать новый раздел в файловую систему NTFS.
  • Шаг 7: Присвойте букву диску для нового раздела.
  • Введите команду «assign letter=[буква]», где [буква] — это буква диска, которую вы хотите назначить для нового раздела.
  • Шаг 8: Выход из Diskpart.
  • Введите команду «exit» для выхода из Diskpart.

Создание разделов на жестком диске windows 10 diskpart

Для тех, кто занимается настройкой компьютеров под управлением Windows 10, создание разделов на жестком диске может быть необходимой задачей. В этой статье мы рассмотрим, как использовать инструмент diskpart для создания разделов на жестком диске в Windows 10.

Что такое diskpart в Windows 10

diskpart — это инструмент командной строки Windows, который предоставляет функции для управления дисками, разделами и томами. Он позволяет управлять различными аспектами жесткого диска, такими как создание, удаление, изменение размера разделов и т.д.

Как использовать diskpart для создания разделов на жестком диске

Прежде чем начать создание разделов, требуется открыть утилиту diskpart из командной строки. Для этого:

  1. Нажмите кнопку «Пуск» и начните вводить «cmd» в строку поиска.
  2. Правой кнопкой мыши щелкните «Командная строка» и выберите «Запуск от имени администратора».

Когда появится окно командной строки, введите команду «diskpart» и нажмите клавишу Enter для запуска утилиты.

Далее представлены команды, которые можно использовать для создания разделов на жестком диске:

list disk — показывает список жестких дисков, подключенных к компьютеру.

select disk [номер диска] — выбирает диск, на котором нужно создать раздел. Номер диска можно узнать из списка жестких дисков.

clean — удаляет все разделы и тома на выбранном диске.

create partition primary size=[размер в Мб] — создает основной раздел на выбранном диске. Размер раздела указывается в мегабайтах.

format fs=[файловая система] — форматирует раздел с указанной файловой системой. Например, format fs=ntfs.

assign letter=[буква диска] — назначает букву диска для нового раздела.

Допустим, у вас есть жесткий диск №1, размер которого 500 ГБ, и вы хотите создать на нем новый раздел в размере 100 ГБ с названием «Новый раздел» и файловой системой NTFS. Для этого выполните следующие шаги:

  1. Запустите diskpart из командной строки.
  2. Введите «list disk» для просмотра списка жестких дисков и определите номер диска, на котором вы хотите создать новый раздел.
  3. Введите «select disk 1» (в зависимости от номера диска) для выбора диска.
  4. Введите «clean» для удаления всех разделов и томов на выбранном диске.
  5. Введите «create partition primary size=102400» для создания основного раздела в размере 100 ГБ.
  6. Введите «format fs=ntfs» для форматирования раздела с файловой системой NTFS.
  7. Введите «assign letter=N» для назначения буквы диска N для нового раздела.
  8. Введите «exit», чтобы закрыть утилиту diskpart.

После выполнения этих команд вы увидите новый раздел на выбранном диске в файловом менеджере.

Заключение

Утилита diskpart предоставляет удобный способ управления дисками, разделами и томами на жестких дисках. Надеемся, что данная статья помогла вам научиться создавать разделы на жестком диске при помощи diskpart в Windows 10.
